# One Letter for Your Day

Exactly one letter, A to Z, standing for the word that describes the day.
`main.ts` writes it to `/output/entry.txt` for the make.fun bounty
[One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36).

The letter: N — for "nightmare". A day that felt like a nightmare: vivid,
funny in a dark way, and true. Chosen over the bounty example Z ("zero
sleep") because Z is the obvious pick every entrant reaches for, while N
carries a sharper, more specific picture.

Run with Node 22: `node main.ts` (writes `/output/entry.txt`, or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
